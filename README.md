# ✊ Pedra, Papel e Tesoura

Jogo interativo de Pedra, Papel e Tesoura desenvolvido com HTML, CSS e JavaScript. O jogador escolhe uma das três opções e enfrenta o computador, que realiza uma jogada aleatória. Ao final, o sistema identifica e apresenta o resultado da partida.

## 🎮 Funcionalidades

- Escolha entre Pedra, Papel ou Tesoura.
- Jogada aleatória realizada pelo computador.
- Identificação automática de vitória, derrota ou empate.
- Exibição das escolhas dos dois jogadores.
- Animações durante a execução da partida.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação da página.
- **CSS3:** estilização da interface e animações.
- **JavaScript:** lógica do jogo, manipulação do DOM e identificação do vencedor.

## 🧠 Conceitos aplicados

Durante o desenvolvimento, foram trabalhados conceitos importantes de JavaScript:

- Seleção e manipulação de elementos do DOM.
- Eventos de clique com `addEventListener`.
- Manipulação de arrays e objetos.
- Geração de valores aleatórios com `Math.random()`.
- Estruturas condicionais e lógica de comparação.
- Manipulação de classes CSS com `classList`.
- Execução de ações com `setTimeout()`.

## ▶️ Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.
4. Escolha Pedra, Papel ou Tesoura e comece a jogar!
